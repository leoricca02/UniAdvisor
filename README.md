**UniAdvisor** is a mobile and cloud-based platform designed to support university students in managing their academic life.  
It provides course reviews, shared study notes, OCR-based document scanning, and smart utilities powered by mobile sensors.

📱 **Android App (Kotlin + Jetpack Compose)**  
☁️ **Cloud Backend (FastAPI + PostgreSQL)**

---

## 🚀 Key Features

- Course and faculty browsing
- Reviews and ratings for courses and professors
- PDF notes sharing and viewing
- OCR document scanning via camera
- Compass, light sensor, and shake-based interactions
- Firebase-based authentication and cloud storage

---

## 🏗 Architecture Overview

- **Frontend:** Native Android app (MVVM, Jetpack Compose)
- **Backend:** REST API with FastAPI
- **Database:** PostgreSQL + Room (local cache)
- **Cloud Services:** Firebase Auth, Firebase Storage, Google Maps
- **Deployment:** Dockerized backend
